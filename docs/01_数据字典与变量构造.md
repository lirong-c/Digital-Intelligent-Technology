# 数据字典与变量构造

本文件说明：论文每个变量来自哪个数据集、用哪些字段、如何计算。对应代码为 `code/generate_paper_tables_figures.py` 的 `build_raw()`（第 270 行起）与 `build_variables()`（第 429 行起）。

## 二、核心变量

| 变量 | 符号 | 定义 | 代码位置 |
|---|---|---|---|
| 数智技术赋能 | `Digit` | `(z(AkrdLn) + z(IntanRatio)) / 2` | `build_variables()` |
| 企业环境绩效 | `EP` | `(z(GreenAppLn) + z(CarbonLn) + z(SubsidyLn)) / 3` | 同上 |
| 绿色技术创新 | `GreenTech` | `ln(1+当年绿色发明专利与实用新型获得量)` | 同上 |
| 管理效率 | `IC` | 内控披露、内控有效、内控改进计划三项虚拟变量之和（0—3） | 同上 |
| 资源配置优化 | `MA` | `ln(1+当年首次公告的绿色并购事件数)` | 同上 |

其中 `z(·)` 为**全样本**均值—标准差标准化（在 1%/99% 缩尾之后计算）。

## 三、控制变量

| 变量 | 定义 |
|---|---|
| `Size` | `ln(资产总计 AT)` |
| `Lev` | `负债合计 LB / AT` |
| `ROA` | `净利润 / AT`（原始字段以百分数给出，除 100） |
| `FAsset` | `固定资产 PPE / AT` |
| `IntAsset` | `无形资产 ITGA / AT` |
| `Cash` | `货币资金 CH / AT` |
| `OCF` | `经营现金流净额 NCPOA / AT` |
| `Growth` | 营业收入同比增速 |
| `AuditFee` | `ln(1+审计费用)` |
| `Audit` | 标准无保留意见取 1，否则 0 |
| `Policy` | `ln(1+省级数字经济政策词频)` |
| `EnvExp` | 地方财政环境保护支出 |

## 四、样本规则（对应论文表 1）

1. 年份 2007—2024；
2. 剔除金融业（行业代码 `IndcodeB` 以 `J` 开头）；
3. 剔除核心变量缺失（`AkrdLn, IntanRatio, GreenAppLn, CarbonLn, SubsidyLn`、全部控制变量、`IndcodeB`、`Prov`）；
4. 连续变量在 1%、99% 分位双侧缩尾；
5. 标准化后合成指数。

→ 结果：**11571 个企业—年度观测、1286 家企业、31 个省级地区**（非平衡面板）。
